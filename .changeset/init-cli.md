New package `@usevyre/init`: one-command setup for useVyre in an existing React or Vue project. `npx @usevyre/init` detects the framework + package manager, installs `@usevyre/react`/`@usevyre/vue`, inserts the self-contained styles import into your entry file (idempotent), and guides the ToastProvider and AI-context steps. Supports `--react`/`--vue`, `--ai <target>`, and `--dry-run`.
